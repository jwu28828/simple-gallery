01 / SITE OBSERVATION

我们看见的，
不只是一面白墙。

从现场照片看，长墙完整、照明已有秩序，地面与踢脚线保持克制。空间并不缺装饰，它缺少一个与空间身份有关的叙事。

01

一段被忽略的停留

走廊目前承担到达与通行的功能，较长的连续墙面缺少可阅读的内容，人的体验多是快速通过。

02

已经具备的优点

顶部连续暖色灯带形成自然的视线引导；相对纯净的浅色墙面，适合承载小体量、低饱和的影像作品。

03

不能牺牲的边界

右侧现有方向导视、左下方疏散标识以及通行和清洁需求必须优先保留，不把装置延伸到地面。

核心判断：不是把墙面填满，而是让每一段留白都成为照片的一部分。
THE THINKING MODEL / 多角色共同判断

不是“挂几张照片”，
而是一项微型空间策展。

推荐采用“策展人 + 空间设计师 + 品牌运营 + 落地工程”四重视角，以一套可复核的判断顺序协调美感、体验与实施风险。

01 / CURATOR

策展视角

为什么看？讲什么故事？照片之间是否有可感知的起承转合？

02 / DESIGNER

空间视角

从行走距离、观看高度、画框节奏、灯光色温和墙面留白出发，保持整体克制。

03 / OPERATOR

运营视角

谁提供作品？多久换一次？能否持续产生真实的社区内容，而不是装完就结束？

04 / BUILDER

落地视角

承重固定、消防避让、清洁维护、预算可控与可拆换，比看起来“很艺术”更重要。

核心决策模型：先守边界 → 再讲故事 → 排布视线 → 一幅试装 → 持续运营 通行与安全是门槛，美学和内容是价值，更新机制决定长期效果。
02 / CURATORIAL CONCEPT
一墙
一程。

展览名称建议为「行走之间」。借助每天必经的长廊，串联“看见地方—看见人—看见正在发生的事”，把一次性的装饰变成一份不断生长的社区影像档案。

CHAPTER 01 / PLACE

在地 · 看见这里

山水、街巷、建筑纹理、光影细节。首先建立空间与地方的联系。

CHAPTER 02 / PEOPLE

相遇 · 看见彼此

人物肖像、工作的片刻、交流与共居，让社区的温度被留下。

CHAPTER 03 / MOMENTS

共创 · 看见发生

工作坊、活动、共同完成的小事。为之后定期换展预留入口。

让方案回到
真实的墙面上。

BEFORE / AFTER

看得见的改变，
尽可能少的打扰。

保持墙面浅色底色与原有灯光不动，仅植入轻质展览构件；让视觉焦点落在摄影作品而不是多余的装饰上。

01多幅作品由小及大透视排列，保持一条统一的视觉中心线。
02柔和低饱和照片适配现有暖光，薄框与留白降低走廊压迫感。
03不遮挡既有导视与疏散标识，墙角、设备和通行面保持原状。

说明：照片和展框均为概念示意，画面透视不代替现场测量；照片内容与具体幅数待甲方确认。

04 / CONTENT SYSTEM

先有内容，
再决定挂几张。

不推荐随机拼贴。首期做“有主题、有排序、有更新逻辑”的小型摄影展，逐步形成空间自己的视觉资产。

01

地方的肌理

用一组与周边环境有关的景物影像开场，让初次到访的人迅速理解“我们身处何处”。

样张仅供风格参考 · 后续替换为在地拍摄
02

发生于此

从社区人物、工作台到生活细节，记录真正生活和工作于此的人，而非摆拍式宣传。

样张仅供风格参考 · 人物肖像需授权
03

下一次相遇

把活动与共创照片留给未来：让展览不是完结稿，而是会随着社区持续生长的公共记忆。

每季可更换一个小主题 · 形成持续内容
05 / MATERIAL & DISPLAY

做减法，
让作品成为主角。

建议先做一幅实体试样，现场确认色温、反光、观看距离与固定方式，再批量制作。

01 / 黑灰细边框 × 暖白卡纸

优先使用薄边、低反光、统一系列的装裱方式；画幅与边框深浅以试装后的现场观感为准。

02 / 统一基线 × 疏密有节

建议先以约 6–8 幅组成第一期，部分画幅作为组合单元；实际数量、间距及中心高度以净墙长和视线测量确定。

03 / 轻量可维护 × 不增加地面占用

采用适合墙体条件且有承重保障的可维护挂装结构，避免凸出装置与落地展架；固定方案需施工方核查。

06 / DELIVERY ROADMAP

从一幅试样，
开始一个可生长的展览。

低干预、可核价、便于迭代。先验证现场效果，再扩展为完整长廊。

01

核对现场

复核净墙长、可用墙高、行走宽度、墙体材料、既有设备和安全标识位置。

02

确定内容

筛出首期主题与照片，确认摄影作者授权、肖像权及统一色调、输出比例。

03

一幅试装

验证色温下的照片表现、抗反光、边框厚度、固定安全与清洁方式。

04

安装与轮换

错开使用高峰施工；保存照片档案和编号，确定换展负责人及更新频率。

07 / VALUE FOR THE SPACE

甲方得到的，
不止是一面更好看的墙。

A

空间记忆点

走廊从中性的过道变为有故事的场景，让客人离开房间后，也能感受到空间的身份和气质。

B

持续的内容资产

照片展可与活动、人物和地方共创同步更新，逐渐形成真实、可累积的空间影像档案。

C

有边界的投入

延用现有灯光与墙面；先核价基础装裱、打印、安装与维护，再决定完整实施规模，不盲目增加硬装。

这四件事。
